
# SOC Investigation Reports

This folder contains investigation reports documenting security monitoring, event analysis, detection testing, findings and recommendations from my SOC lab.

## Investigation 001: Windows Process Creation Detection

**Platform:** Wazuh SIEM

**Endpoint:** Windows

**Event ID:** 4688 – Process Creation

**Custom Detection Rule:** 100100

### Investigation Objective

To develop and validate a custom Wazuh detection rule that identifies a controlled Windows process creation event containing a specific command-line marker.

### Testing Performed

- Positive detection test using SOC_LAB_TEST.
- Negative detection test using NORMAL_PROCESS_TEST.
- Verification of alerts generated by Wazuh.
- Review of process names, parent processes and command-line data.

### Outcome

The custom rule successfully detected the controlled positive test and did not trigger on the separate negative test.

The activity was performed in a controlled lab environment and did not represent a confirmed security incident.

The full investigation report will be added to this folder.
